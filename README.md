# Greco Picks

Weekly NFL pick'em for the Greco family and friends: tap the winner of each game,
picks lock at kickoff, and records, standings and stats update automatically.

- **App:** https://pauljgreco.github.io/GrecoPicks/ (open your personal link once, then install it)
- **Backend:** a Google Sheet + Apps Script that pulls the schedule and scores and grades picks
- `config.js` holds the Apps Script web app address the app talks to
